# Timber docs

Timber is a cross-platform device tree viewer: a Tauri v2 desktop app with a Leptos UI, plus a web build for viewing files.

| Doc | What it holds |
|---|---|
| [DESIGN.md](DESIGN.md) | The current design: architecture, formats, SSH, diff, UI. |
| [DECISIONS.md](DECISIONS.md) | Numbered decisions with their reasons and the alternatives we rejected. |
| [ROADMAP.md](ROADMAP.md) | Milestones and progress checklist. |

## Keeping these up to date
- When a decision is made or changed, add a `D-xxx` entry to DECISIONS.md and update DESIGN.md to match.
- When work lands, tick it in ROADMAP.md.
- Open questions live in DESIGN.md until they're resolved, then move to DECISIONS.md.
